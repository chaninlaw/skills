# Engineering

Skills for daily code work.

## User-invoked

Reachable only when you type them (Claude Code: `disable-model-invocation: true`).

- **[architect-scout](./architect-scout/SKILL.md)**: Explore and research architecture patterns from tech blogs and industry case studies, sketch candidate code shapes, and resolve hard architecture decisions for Wayfinder tickets.
- **[create-verification-skill](./create-verification-skill/SKILL.md)**: Generate a project-local verification skill that drives your app the way a user does, with a feature map of user-facing behavior.
- **[maintain-verification-skill](./maintain-verification-skill/SKILL.md)**: Periodic pass that keeps a verification skill and its feature map honest, shipping at most one PR of proven corrections.

## Model-invoked

- **[post-review](./post-review/SKILL.md)**: Turn code-review findings into consistent GitHub PR review comments and post them as one review after you approve a preview.
- **[pr-review](./pr-review/SKILL.md)**: Review a pull request or merge request end-to-end by running code-review on the diff, then handing findings to post-review to format and post.
